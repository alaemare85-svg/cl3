# موقع wcl3 وقوالب Java

يحتوي الموقع على اسم متحرك، ونموذج للبحث في Google، وروابط إلى منصات التواصل الاجتماعي، وقسمًا للموسيقى ونادي الاتحاد. كما يتضمن مثالًا مستقلًا بلغة Java.

## تشغيل مثال Java

ثبّت JDK وتأكد من إضافته إلى `PATH`. افتح PowerShell في مجلد المشروع وتحقق من توفر أدوات Java:

```powershell
java -version
javac -version
```

بعدها ترجم البرنامج وشغّله:

```powershell
javac Main.java
if ($LASTEXITCODE -eq 0) { java Main }
```

## صفحة الويب

افتح `index.html` مباشرة في المتصفح. ملفات الصفحة منفصلة لتسهيل التعديل:

- `index.html` لبنية الصفحة.
- `styles.css` للألوان والتنسيق.
- `script.js` للبحث ومؤثرات الخلفية وإعدادات اللغة والألوان.

روابط التواصل الحالية تفتح الصفحات الرئيسية للمنصات، وتُحمّل شعاراتها من Simple Icons CDN. استبدل عناوين الروابط في `index.html` بروابط حساباتك عند الحاجة.

تستخدم الصفحة خلفية داكنة صافية قابلة للتغيير من الإعدادات، مع مؤثرات shader متحركة وتوهج حول البحث؛ يتوقف التحريك عند تفعيل إعداد تقليل الحركة. تُحمّل المؤثرات من مكتبة `shaders` عبر esm.sh، وتتطلب WebGL.

## التفضيلات والخصوصية

تتضمن الإعدادات أنماطًا داكنة للمحيط والبنفسجي والغابة والأحمر، إضافة إلى منتقي ألوان مخصص. تُحفظ اللغة والنمط ولونا الخلفية والنص في `localStorage` على جهاز المستخدم فقط. لا يضيف الموقع إعلانات أو أدوات تحليل، لكن Google وYouTube ومزوّدي الصور والملفات الخارجية قد يسجلون طلبات الاتصال وفق سياساتهم. صفحة ويب ثابتة لا تعمل كمتصفح مستقل ولا تستطيع حجب التتبع أو الإعلانات داخل مواقع أخرى.
