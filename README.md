# موقع wcl3 وقوالب Java

يحتوي الموقع على اسم متحرك، ونموذج للبحث في Google، وروابط إلى منصات التواصل الاجتماعي، وقسمًا للموسيقى ونادي الاتحاد. كما يتضمن مثالًا مستقلًا بلغة Java.

## تشغيل مثال Java

ثبّت JDK وتأكد من إضافته إلى `PATH`. افتح PowerShell في مجلد المشروع وتحقق من توفر أدوات Java:

```powershell
java -version
javac -version
```

بعدها ترجم البرنامج وشغّله:

```powershell
javac Main.java
if ($LASTEXITCODE -eq 0) { java Main }
```

## إعداد تسجيل حسابات العملاء

تستخدم الصفحة Supabase Auth لإنشاء الحسابات وتسجيل الدخول. لتفعيلها:

1. أنشئ مشروعًا في Supabase.
2. من إعدادات المشروع، انسخ `Project URL` والمفتاح العام `Publishable key` (أو `anon`).
3. استبدل `YOUR_PROJECT_ID` و`YOUR_SUPABASE_PUBLISHABLE_KEY` في بداية `script.js` بقيم مشروعك.
4. في إعدادات Authentication > URL Configuration، أضف `https://alaemare85-svg.github.io/cl3/` إلى عناوين الموقع وإعادة التوجيه المسموح بها، وفعّل تأكيد البريد الإلكتروني.

لا تضع مفتاح `service_role` أو أي مفتاح سري في ملفات الموقع؛ المفتاح العام فقط مناسب للاستخدام في المتصفح. قد تحتاج إلى إعداد SMTP خاص لإرسال رسائل التأكيد للعملاء.

## صفحة الويب

افتح `index.html` مباشرة في المتصفح. ملفات الصفحة منفصلة لتسهيل التعديل:

- `index.html` لبنية الصفحة.
- `styles.css` للألوان والتنسيق.
- `script.js` للبحث وتسجيل الدخول وإدارة جلسة العميل ومؤثرات الخلفية وإعدادات اللغة والألوان.

روابط التواصل الحالية تفتح الصفحات الرئيسية للمنصات، وتُحمّل شعاراتها من Simple Icons CDN. استبدل عناوين الروابط في `index.html` بروابط حساباتك عند الحاجة.

تُحمّل مؤثرات الخلفية من مكتبة `shaders` عبر esm.sh، وتتطلب WebGL. تُعطّل الحركة تلقائيًا عند تفعيل إعداد تقليل الحركة في الجهاز.

## التفضيلات والخصوصية

تُحفظ اللغة ولونا الخلفية والنص في `localStorage` على جهاز المستخدم فقط، ولا تُرسل إلى حساب Supabase. لا يضيف الموقع إعلانات أو أدوات تحليل، لكن Google وYouTube وSupabase ومزوّدي الصور والملفات الخارجية قد يسجلون طلبات الاتصال وفق سياساتهم. صفحة ويب ثابتة لا تعمل كمتصفح مستقل ولا تستطيع حجب التتبع أو الإعلانات داخل مواقع أخرى.
