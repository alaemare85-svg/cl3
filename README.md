# موقع wcl3 وقوالب Java

يحتوي الموقع على اسم متحرك، ونموذج للبحث في Google، وروابط إلى منصات التواصل الاجتماعي. كما يتضمن مثالًا مستقلًا بلغة Java.

## تشغيل مثال Java

تحتاج إلى تثبيت JDK. من مجلد المشروع شغّل:

```text
javac Main.java
java Main
```

## صفحة الويب

افتح `index.html` مباشرة في المتصفح. ملفات الصفحة منفصلة لتسهيل التعديل:

- `index.html` لبنية الصفحة.
- `styles.css` للألوان والتنسيق.
- `script.js` للتحقق من كلمات البحث.

روابط التواصل الحالية تفتح الصفحات الرئيسية للمنصات. استبدل عناوينها في `index.html` بروابط حساباتك عند الحاجة.
