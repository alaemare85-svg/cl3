# موقع wcl3 وقوالب Java

يحتوي الموقع على واجهة بحث، ومفضّلات الموسيقى ونادي الاتحاد، ومربعًا صغيرًا لروابط التواصل، وإعدادات أعلى الصفحة، ومعاينة شكلية غير تفاعلية لبطاقة الوصول. كما يتضمن مثالًا مستقلًا بلغة Java.

## تشغيل مثال Java

ثبّت JDK وتأكد من إضافته إلى `PATH`. افتح PowerShell في مجلد المشروع وتحقق من توفر أدوات Java:

```powershell
java -version
javac -version
```

بعدها ترجم البرنامج وشغّله:

```powershell
javac Main.java
if ($LASTEXITCODE -eq 0) { java Main }
```

## صفحة الويب

افتح `index.html` مباشرة في المتصفح. ملفات الصفحة منفصلة لتسهيل التعديل:

- `index.html` لبنية الصفحة.
- `styles.css` للألوان والتنسيق والخلفية المتحركة.
- `script.js` للبحث وإعدادات اللغة والألوان.

روابط التواصل الحالية تفتح الصفحات الرئيسية للمنصات، وتُحمّل شعاراتها من Simple Icons CDN. استبدل عناوين الروابط في `index.html` بروابط حساباتك عند الحاجة.

تستخدم الصفحة خلفية داكنة بتوهج لوني متحرك عبر CSS، دون صور خلفية أو مؤثرات shader. يتوقف التحريك عند تفعيل إعداد تقليل الحركة، وتوجد إعدادات اللغة والألوان في قائمة أعلى الصفحة.

## التفضيلات والخصوصية

تتضمن الإعدادات أنماطًا داكنة للمحيط والبنفسجي والغابة والأحمر، إضافة إلى منتقي ألوان مخصص. تُحفظ اللغة والنمط ولونا الخلفية والنص في `localStorage` على جهاز المستخدم فقط. لا يضيف الموقع إعلانات أو أدوات تحليل، لكن Google وYouTube ومزوّدي الصور والملفات الخارجية قد يسجلون طلبات الاتصال وفق سياساتهم. صفحة ويب ثابتة لا تعمل كمتصفح مستقل ولا تستطيع حجب التتبع أو الإعلانات داخل مواقع أخرى.

بطاقة الوصول المعروضة معاينة شكلية فقط؛ حقولها وزرها معطّلة ولا تنفذ تسجيل دخول أو ترسل أو تحفظ بيانات. لا يضيف الموقع أدوات تحليل أو حسابات؛ إعداداته محلية، ويُرسل البحث إلى Google عند تقديمه فقط. تمنع الصفحة إرسال المُحيل إلى الروابط الخارجية، مع ملاحظة أن مزوّدي الصور والروابط الخارجية قد يسجلون اتصالاتهم وفق سياساتهم.
