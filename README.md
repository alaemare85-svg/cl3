# قوالب بداية Java والويب

يحتوي هذا المشروع على مثال مستقل بلغة Java وصفحة ويب بسيطة باستخدام HTML وCSS وJavaScript.

## تشغيل مثال Java

تحتاج إلى تثبيت JDK. من مجلد المشروع شغّل:

```text
javac Main.java
java Main
```

## تشغيل صفحة الويب

افتح `index.html` مباشرة في المتصفح. ملفات الصفحة منفصلة لتسهيل التعديل:

- `index.html` لبنية الصفحة.
- `styles.css` للألوان والتنسيق.
- `script.js` للتفاعل.

يمكنك البناء على هذه الأمثلة وإضافة ملفاتك ومكوناتك الخاصة.
